# Evidence report contract

After each experiment, run `bash scripts/report.sh A` or `B`. The generated `reports/<run>/report.md` and `result.json` record the pinned baseline, candidate commit, changed file count, genuine verification exit codes, and available evidence. Copy `experiments/observations.template.json` to `reports/<run>/observations.json` to add participant-observed model/provider, agent outcome, UTC setup and agent timestamps, tool calls, and token data. Referenced evidence files must be placed in the same run directory. Setup and agent durations are calculated separately. Missing measurements remain **NOT_AVAILABLE**.

The report script never declares that Copilot ran or fixed Django without participant-supplied evidence. Attach the actual Copilot conversation/export or leave `agent_execution_status` as `NOT_OBSERVED`. Record human interventions and a concise patch review. Keep A and B reports separate. A passing command is one part of verification, not proof that the agent's full task is complete. Run `python3 scripts/results.py compare` after both reports; it writes `reports/comparison.md` and `comparison.json`. The token formula runs only when both totals have attached provider reports and matching task, model, mode, runtime, and verification checks. One comparison is exploratory, not statistically conclusive.
